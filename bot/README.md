# Telegram-бот

Отдельный Node.js-проект внутри репозитория расширения. Файлы расширения остаются в корне; код бота, зависимости и его `.env` находятся в `bot/`.

## Команды

- `/start` показывает первый экран.
- `/test` открывает раздел тестирования с inline-кнопкой запуска Chromium.

Другие команды не регистрируются.

Кнопка запускает Chromium через Playwright в новом временном профиле и загружает расширение из корневого каталога проекта. Портал не открывается автоматически: перейдите на него вручную после запуска окна. Профиль очищается после закрытия Chromium.

## Настройка

1. Установите Node.js версии 20 или новее.
2. Откройте `bot/.env` и задайте токен, полученный у BotFather:

   ```env
   TELEGRAM_BOT_TOKEN=сюда_вставить_токен
   ```

3. В терминале перейдите в каталог `bot` и установите зависимости:

   ```sh
   npm install
   ```

4. Установите Chromium для Playwright:

   ```sh
   npx playwright install chromium
   ```

5. Запустите polling:

   ```sh
   npm start
   ```

Для перезапуска при изменениях исходников используйте `npm run dev`.

Бот должен работать на компьютере с графической сессией: inline-кнопка запускает видимое окно Chromium на том же компьютере.

`.env` и `node_modules/` исключены локальным `.gitignore`. Не публикуйте и не отправляйте токен в чат.
