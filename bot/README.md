# Telegram-бот и Chromium fingerprint lab

Отдельный Node.js-проект внутри репозитория расширения. Код бота, зависимости и его `.env` находятся в `bot/`; файлы расширения остаются в корне.

## Запуск

- `/start` — первый экран.
- `/test` — кнопка запуска Chromium с локальной диагностикой.

В каталоге `bot` выполните `npm install`, `npx playwright install chromium`, затем `npm start`. Требуется Node.js 20+ и графическая сессия.

## Профили браузера

Профили хранятся в `src/fingerprint-profiles.js`. Выбрать профиль можно переменной окружения перед запуском:

```powershell
$env:BROWSER_PROFILE = "desktopDefault"
npm start
```

Доступны `desktopDefault` и `windowsDesktop`. Они задают поддерживаемые параметры Playwright: locale, viewport/screen, цветовую схему и reduced motion. Если `timezoneId`, `geolocation` или `userAgent` равны `null`, соответствующее значение не подменяется. По умолчанию User-Agent остаётся согласованным с фактически запущенным Chromium.

## Диагностика

После запуска открывается локальная read-only страница. Она показывает доступные сайту значения: UA, язык, часовой пояс, размеры экрана, DPR, CPU/RAM hints, WebGL, доступность API, media devices и speech voices. Кнопка копирования сохраняет JSON только в буфер обмена по явному нажатию пользователя. Сетевой отправки результатов нет.

Некоторые значения зависят от ОС, драйвера, разрешений и версии Chromium. WebGPU, Battery API и deviceMemory могут быть недоступны. Локальная страница не может надёжно прочитать MAC-адрес или имя Windows-компьютера.

Этот стенд не внедряет скрытый шум в Canvas/WebGL/AudioContext и не подделывает системные устройства: он нужен для измерения фактического поведения браузера и проверки настроек без маскирующих патчей.

## Безопасность

`.env` и `node_modules/` исключены локальным `.gitignore`. Не публикуйте токен Telegram.
