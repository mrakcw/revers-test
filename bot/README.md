# Telegram-бот

Отдельный Node.js-проект внутри репозитория расширения. Файлы расширения остаются в корне; код бота, зависимости и его `.env` находятся в `bot/`.

## Команды

- `/start` показывает первый экран.
- `/test` показывает справку по запуску.
- `/run` показывает кнопки выбора одного из трёх клиентов из `bot/test-data.js`.
- Нажатие на кнопку клиента запускает для него отдельное окно Firefox.
- `/stop` закрывает окно Firefox текущего запуска.

Другие команды не регистрируются.

Бот запускает Firefox через Playwright без расширения, с настройками приватного режима и системных корневых сертификатов. Перед переходом проверяется геолокация внешнего IP: без Испании переход блокируется. Сценарий остановится перед CAPTCHA, SMS и подтверждением записи.

## Настройка

1. Установите Node.js версии 20 или новее.
2. Откройте `bot/.env` и задайте токен, полученный у BotFather:

   ```env
   TELEGRAM_BOT_TOKEN=сюда_вставить_токен
   ```

3. В терминале перейдите в каталог `bot` и установите зависимости:

   ```sh
   npm install
   ```

4. Установите Firefox для Playwright:

   ```sh
   npx playwright install firefox
   ```

   При необходимости задайте `TARGET_LINK`; по умолчанию открывается начальная страница ICP.

5. Запустите polling:

   ```sh
   npm start
   ```

Для перезапуска при изменениях исходников используйте `npm run dev`.

Бот должен работать на компьютере с графической сессией: inline-кнопка запускает видимое окно Firefox на том же компьютере.

`.env` и `node_modules/` исключены локальным `.gitignore`. Не публикуйте и не отправляйте токен в чат.
