# CitaExtForGoogle

## Назначение файлов

- `background.js` управляет запуском и остановкой автоматизации, активной вкладкой и сетевыми ошибками.
- `content.js` взаимодействует с порталом: распознает текущую страницу, заполняет поля и обрабатывает шаги записи.
- `popup.html`, `popup.css` и `popup.js` реализуют окно расширения, авторизацию, форму пользователя и выбор офиса.
- `procedures.js` содержит справочники процедур, провинций, метаданных форм и офисов.
- `redirect.html` и `redirect.js` показывают паузу при недоступности сайта и затем возвращают пользователя на портал.
- `manifest.json` задает версию расширения, разрешения, фоновой обработчик, popup и подключение скрипта страницы.
- `logs.txt` содержит диагностические записи; перед передачей файла другим людям проверьте его на персональные данные и учетные сведения.
- `icon-16.png`, `icon-48.png` и `icon-128.png` являются изображениями значка расширения.
- `_metadata/verified_contents.json` содержит метаданные проверки целостности файлов.

## Справочники

В `PROCEDURES` ключом служит идентификатор процедуры портала, значением — ее название. `CITIES` сопоставляет название провинции со списком доступных идентификаторов процедур. `PROCEDURE_META` задает для пары «процедура + провинция» доступность элементов формы и особенности входа. `OFFICES` хранит значения и отображаемые названия офисов по провинциям.

## Форматы и комментарии

Код JavaScript, HTML и CSS снабжен пояснениями на русском языке. `manifest.json` и файл проверки целостности являются JSON: комментарии в них недопустимы. Файл проверки целостности оставлен без изменений; поскольку он содержит хеши исходных файлов, добавление комментариев к исходникам приводит к несовпадению этих хешей. Бинарные значки и журнал событий также не являются исходным кодом для комментирования.
